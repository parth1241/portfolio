# Parth Karan — Full-Stack & Web3 Engineer Portfolio

Welcome to my premium, interactive developer portfolio. This is a highly polished, single-page horizontal scrolling experience designed to showcase my engineering background and selected Web3/Full-Stack projects.

## 🌟 Features & Aesthetics

- **River & Mountain Path Canvas Animation**: A custom, full-screen canvas background that mimics a flowing river or a path winding through the mountains with elegant interactive particles.
- **Horizontal Scrolling Layout**: A sleek, horizontal flow across desktop viewports, using high-end scroll mechanics and fluid page transitions.
- **Flawless Mobile Experience**: Dynamic vertical touch gestures mapping directly to the horizontal flow on mobile devices, ensuring zero awkward horizontal overflows.
- **Tech Cloud Grid**: Categorized presentation of my tech stack spanning Languages, Frameworks, Blockchain (Stellar/Web3), and DevOps/Tools.
- **Express Backend**: Minimal, high-performance Node/Express server handling static assets and API interactions.

---

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+), CSS3
- **Server**: Node.js, Express.js
- **Styling**: Vanilla CSS (Fluid grids, CSS Custom Properties, and micro-animations)
- **Deployment & Hosting**: Docker, Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/parth1241/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
